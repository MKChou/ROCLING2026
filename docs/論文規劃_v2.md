## 一、定位與賣點

- **場景**：高齡 ACP 語音互動平台的 ASR 後端選型（國語＋台語、醫療敏感詞、高齡語音特性）
- **賣點 1（管線比較）**：以可整合管線為單位——準確度／延遲資源／語言覆蓋／輸出穩健性（不另提「五維框架」）
- **賣點 2（診斷集）**：自建 100 段幻覺診斷集（靜音/噪音/極短語音/猶豫音/ACP 對照）
- **賣點 3（實證發現）**：
  1. D2 在正確 `lang=TA and ZH Medical V1` 下台語可用（CER 9%、recall 86%）；誤用舊 lang 則 CER 88%、recall 11%——**integration error baseline**
  2. 兩系統靜音/噪音幻覺率 0%、關鍵詞幻覺 0 次，但**極短語音/猶豫音會被升級成實詞**（啊→好）
  3. D5 GPU 延遲 0.18 s 優勢明顯，一般國語 CER 略優；D2 Medical V1 為換取台語之必要取捨（D2/D5 皆用 OpenCC）

## 二、研究問題（配合實測範圍修訂）

- **RQ1** 準確度與延遲/資源權衡：D2 vs D5，國語/台語/ACP 關鍵詞 → 表 2＋圖 1
- **RQ2** 非典型輸入之幻覺風險：100 段診斷集 → 表 3＋錯例表
- **RQ3** 語言覆蓋與 API 整合：D2 Medical V1 台語 CER + recall vs 整合錯誤基線 → 5.3 節 + 表 lang_ablation
