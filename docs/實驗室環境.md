## Python 環境說明

本機有兩種用法：

1. **系統 Python（目前可用）**：先前已安裝 torch / transformers 等，直接執行 `python scripts/...` 即可。
2. **專案 venv（`.venv`，建議長期使用）**：執行 `setup_env.ps1` 建立。若實驗室網路不穩導致 pip 失敗，可稍後重試：

```powershell
.\.venv\Scripts\pip install -r requirements.txt
```

驗證：`python scripts/env/verify_env.py`

## 一鍵架設

在專案根目錄（PowerShell）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\env\setup_env.ps1
```

會自動：
1. 檢查 / 安裝 ffmpeg
2. 建立 `.venv` 並安裝 `requirements.txt`
3. 將 `data/legacy_pilot/acp_wavs/acp_*.wav` 統一為 16 kHz 單聲道
4. 預載 Nemotron 0.6B 模型
5. 執行環境驗證

## 日常使用

```powershell
cd ROCLING2026
.\.venv\Scripts\Activate.ps1

# 檢查環境
python scripts/env/verify_env.py

# 新錄音轉檔（WAV 任意取樣率）
python scripts/prep/convert_acp_wavs.py

# D5 實驗
python scripts/exp/run_d5.py e1 --testset acp --manifest data/manifests/acp.csv
python scripts/exp/score.py e1 --profile D5
python scripts/exp/run_d5.py e3 --manifest data/manifests/hallucination_C1.csv
python scripts/exp/score.py e3 --profile D5
```

## 疑難排解

| 問題 | 處理 |
|------|------|
| CUDA OOM | `run_d5.py` 加 `--device cpu` |
| 模型下載慢 | 設定 `HF_TOKEN` 或離線快取 |
| ffmpeg 找不到 | 重開終端機或執行 setup_env.ps1 |
