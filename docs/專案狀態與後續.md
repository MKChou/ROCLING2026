## 二、核心結果速查（論文用）

### 部署方案

| 編號 | 方案 | 說明 |
|------|------|------|
| **D2** | Whisper large-v3-turbo API | 雲端後端；**lang=TA and ZH Medical V1**（與 VOICE app STT 一致；非 TTS 之 zh/en/tw）；伺服器端 OpenCC s2twp + 靜音標記 `<{silent}>` |
| **D5** | Nemotron 0.6B 本機串流 | 裝置端後端；僅簡體 zh-CN → app 端 OpenCC s2twp；不支援台語 |

> **重要**：D2、D5 **皆使用 OpenCC**；D5 劣勢主因是簡體解碼起點聽錯同音字，非「只有 D5 才轉繁」。

### 數字（Medical V1 主結果，2026-07-07）

| 指標 | D2（Medical V1） | D5 |
|------|------------------|-----|
| 國語 CER（500） | 6.48% | **5.57%** |
| 台語 CER（500） | **9.0%** | N/A |
| 台語詞彙命中率 recall | **86.06%** | N/A |
| ACP 關鍵詞錯誤率（50） | **31.88%** | 39.13% |
| E2 延遲（國語 50 句，2026-07-15） | **0.24 s**（含網路） | **0.42 s（CPU）**；本次無 CUDA，不報 GPU |
| E3 極短+猶豫不符 | **35/40**（空8+非空27） | **30/40**（空20+非空10） |
| 幻覺率 C1+C2（40 段） | **0%** | **0%** |
| ACP 關鍵詞幻覺 | **0** | **0** |

**整合錯誤基線**（舊 `lang=Chinese & Taiwanese`，非主結果）：台語 CER 88.35%、recall 11.22%；國語 CER 2.60%、ACP 關鍵詞錯 17.39%。見 `results/analysis/integration_error_baseline.csv`。

資料來源：`results/E1_accuracy.csv`、`results/E2_performance.csv`、`results/E3_hallucination.csv`  
台語 recall：`python scripts/analysis/tw_keyword_recall.py`

### APP 選型注意事項（VOICE 平台；2026-07-15 嚴格審查對齊稿）

> **硬結論**：雙語覆蓋與 ACP 關鍵詞正確率互斥；**任一管線皆不宜直接驅動簽署／意願確認**。

1. **需國台語雙語、有網路** → 僅 D2 + Medical V1 具台語覆蓋；須接受 ACP 關鍵詞錯≈31.9%（舊 lang 17.4%）
2. **僅國語、優先壓低 ACP 關鍵詞錯** → 勿預設 Medical V1；舊 lang 國語 2.6%／ACP kw 17.4% 更優，須另評
3. **離線、僅國語** → 可考慮 D5 CPU（接受關鍵詞錯、台語 N/A；本測延遲高於含網路雲端；未測 GPU／首字）
4. **所有方案** → 極短/猶豫必須對話層確認（分漏接 vs 非空改寫）
5. **L-legacy × E3（已補）** → 服藥改寫 0/20；不符 20/40（vs M-V1 35/40）
6. **公開 Whisper（已補）** → 國語50 CER 2.33%；無 VAD 時靜音/底噪非空 **40/40**；不要* 無服藥改寫
7. **C5 對照** → M-V1 10.7%／L-legacy 4.8%／D5 9.9%／公開 6.3%（各 20 句）
