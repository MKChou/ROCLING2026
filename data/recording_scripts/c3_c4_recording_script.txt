# ACP-DRP C3／C4 錄音稿
# 用途：部署風險探針主表（漏接／高風險改寫）；擴充為男女各 50 句
# 語言：國語；男女念同一詞表
#
# 錄音規格
# - 格式：16 kHz、單聲道、wav
# - 語者：1 男 + 1 女（與 C5 同一批為佳）
# - 麥克風／距離／環境盡量與 C5 一致
# - 語速自然，像跟醫護短答，不必刻意放慢或誇張
# - 檔名：
#     C3：c3_001.wav … c3_050.wav（每位語者各自一份）
#     C4：c4_001.wav … c4_050.wav
# - 目錄建議：data/acp_drp/C3_short/{male,female}/ 、data/acp_drp/C4_hesitation/{male,female}/
# - 本檔位置：data/recording_scripts/c3_c4_recording_script.txt
#
# C3 特別注意（建構效度）
# - 錄完後必須裁切前後長靜音，只留語音段再送 ASR
# - 禁止「短內容 + 前後數秒靜音」混進 C1 效應
# - 錄時前後各留約 0.3–0.5 秒安靜即可，方便後製裁切
#
# C4 特別注意
# - 念的是猶豫／填充音，不是有意義的短句
# - 「嗯」「呃」「欸」等可略作音高／長度變化，但 reference 仍依本表
# - 不要念成「嗯好」「對啊」——那些屬於 C3
#
# 錄畢檢查（2026-07-17 完成）
# [x] 男女各完成 C3 50 + C4 50（共 200 段）
# [x] 16 kHz mono wav（`scripts/prep/build_c3_c4.py`）
# [x] C3 已裁切前後長靜音
# [x] manifest：`data/manifests/c3_short.csv`、`c4_hesitation.csv`

================================================================================
錄音進行建議（給協助錄音的人）
================================================================================

1. 先錄 C3，再錄 C4（或分兩段時間），避免兩種任務混在一起。
2. 每句單獨存檔；唸錯就整句重錄該檔，不要把多句貼在同一個 wav。
3. C3：清楚短念即可；「不要了」「不要啊」請自然，不要特別強調。
4. C4：像在想事情時的聲音；「那個／就是／然後／這個」當填充音，不要講完整句。
5. 錄完回報：語者代號（male／female）、麥克風、是否安靜室內、每句是否已對稿。

================================================================================
後製／匯入（研究端）
================================================================================

- C3 裁切前後長靜音後再進 ASR
- 建立 manifest：audio_path,reference_text,language,condition,speaker
  例：C3_short/male/c3_009.wav,不要了,zh-tw,C3,male
- 男女各 50 → C3 100 段、C4 100 段；重跑後才可替換主表 tab:halluc 數字
